- JavaScript

## Local Development

Install dependencies:

npm install

Start the development server:

npm run dev

Build for production:

npm run build

Preview the production build locally:

npm run preview

## Deployment

This project is currently built with Vite and deployed through Hostinger.

For manual deployment:

Run:
npm run build
